# VEROXA — подготовка к Android

## Важно

Этот архив сохраняет исходный веб-магазин VEROXA без изменения его интерфейса и функций. В нём пока нет готового Android-приложения, APK или AAB. Этот документ описывает дальнейший бесплатный путь, не меняя текущий магазин.

## Что уже есть

- Полные исходники веб-магазина в `artifacts/zyvanta/`.
- Корневые манифесты workspace и `pnpm-lock.yaml`.
- README с инструкциями по локальному запуску.

## Рекомендуемый путь без переделки сайта

Для первого Android-пакета можно рассмотреть Android-оболочку, которая открывает опубликованный сайт VEROXA. Это быстрее сохраняет текущий внешний вид, но требует проверки навигации, загрузки изображений, поведения корзины и сетевых ошибок. Более надёжный вариант — упаковать веб-приложение как Android-приложение с Capacitor; это потребует отдельной конфигурации Android и локальной сборки.

Не заменяйте исходники магазина и не удаляйте файлы из `artifacts/zyvanta/`. Сначала создайте отдельную ветку Git для Android-подготовки.

## Перед локальной сборкой

1. Установите Node.js и pnpm на компьютер.
2. Распакуйте архив в отдельную папку.
3. Выполните команды запуска из `README.md`, чтобы проверить исходный сайт.
4. Создайте Git-репозиторий и сохраните исходную версию.
5. Только после проверки выберите способ упаковки для Android и добавьте Android-конфигурацию отдельно от исходного интерфейса.

## Google Play

Для публикации Android-приложения обычно требуется подписанный Android App Bundle (`.aab`), заполненная карточка приложения и соблюдение актуальных правил Google Play. Создание аккаунта разработчика может требовать разового платежа Google; поэтому полностью бесплатный процесс публикации гарантировать нельзя. Разработка и локальная сборка могут выполняться без платных сервисов.
